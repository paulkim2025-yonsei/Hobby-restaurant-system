
# 🍻 Pub Order Management System (Flask)

> 취미로 진행해본 프로젝트로, 처음으로 프론트엔드, 백엔드, AWS DB관리, 배포까지 혼자서 완성해본 프로그램입니다.
> **테이블 주문 → 주방 조리 → 관리자 정산** 흐름을 하나의 웹 앱으로 통합한 **주점·레스토랑용 주문/재고 관리 플랫폼**입니다.  
> 고객 UX, 주방 동선, 관리자 편의성을 모두 고려해 **실시간 상태 모니터링·경고·로그 기록** 기능을 제공합니다.

---

## ⚙️ 주요 기능

| 모듈 | 설명 |
|------|------|
| **주문(Order)** | - 테이블·인원·주문 종류 선택<br>- 품절/재고 규칙 즉시 검증<br>- 최초 주문 시 맥주 병수 제한 등 비즈니스 룰 적용 |
| **주방(Kitchen)** | - 메뉴별 “미조리 수량” 실시간 집계<br>- `+N 조리 완료` 버튼으로 재고 차감·화면 갱신 |
| **관리(Admin)** | - 주문 상태 `pending → paid → completed/rejected` 전환<br>- 입금확인/거절, 테이블 차단·비우기, 0원 서비스 등록<br>- 경과 시간별 색상 경고·실시간 매출 합계<br>- 역할·행동·세부 내용을 저장하는 상세 로그 |
| **공통** | - 로그인/세션 기반 권한 제어<br>- 한국 시간 `HHMMSS` 포맷으로 시간 통일<br>- Bootstrap + Jinja2 템플릿 레이아웃 |

---

## 🏷️ 데이터베이스 스키마 (MySQL + SQLAlchemy)

| 테이블 | 핵심 컬럼 | 용도 |
|-------|----------|------|
| `Menu` | `id`, `name`, `price`, `stock`, `sold_out` | 메뉴·재고 |
| `Order` | `id`, `table_no`, `people`, `state`, `created_hms` | 주문 헤더 |
| `OrderItem` | `id`, `order_id`, `menu_id`, `qty` | 주문 상세 |
| `Setting` | `id`, `main_limit`, `beer_limit`, ... | 비즈니스 룰 |
| `Log` | `id`, `actor`, `action`, `detail`, `hms` | 관리자 이벤트 로그 |

> **규칙 자동화**  
> - `current_hhmmss()` 유틸로 **Asia/Seoul** 기준 HHMMSS 형식 저장  
> - 백그라운드 쓰레드가 50/60분 경과 주문을 주기적으로 검사하여 **1·2차 경고 (퇴장경고)** 및 로그 기록
